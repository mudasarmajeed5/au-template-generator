## Integrated AU collection

The user confirmed separate redistribution permission on 7 November 2026. Adapted files live in public/templates/collection and are generated by scripts/adapt-university-covers.py. They retain the downloaded backgrounds, replace floating sample text with native editable paragraphs, use the existing public/aulogo.png asset, and prefill Air University. Arial replaces unused embedded display fonts for predictable rendering and smaller downloads. Original downloaded files remain here as reproducible inputs.

The app exposes five lab designs, five assignment designs supporting both individual and group modes, and two project designs. prepareDocument adds documentLabel, coverTitle and submittedBy to the usual form fields. submittedBy is a multiline string built from the existing member records, and docxtemplater renders its line breaks. Native form fields and original template paths continue to use the existing generation core. Client downloads and the API fallback both forward coverDesign.

Validation included the original six smoke cases, 17 new populated cases, all twelve API fallback selections, LibreOffice PDF rendering of long-content/five-member samples to one page, and live browser previews and a group download. Microsoft Word itself was not available. Extremely long unbounded inputs can exceed a page, as they can with existing templates.
